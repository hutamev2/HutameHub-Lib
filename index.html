Library:CreateWindow(config)

Ana pencereyi, başlık çubuğunu, minimize/kapat butonlarını ve sekmelerin dizileceği sol kenar çubuğunu oluşturur.

→ Returns: Window Object
Parametre Tip Varsayılan Açıklama
Title string "Toxin Hub" Sol üst köşede görünen ana başlık
Subtitle string "UI" Başlığın yanında vurgu rengiyle duran sürüm etiketi
Theme string "Dark" Koyu arka plan renk seti (#0F0F0F, #191919)
Accent Color3 Color3.fromRGB(0, 255, 128) Slider, aktif sekmeler ve anahtarların vurgu rengi
Size UDim2 UDim2.fromOffset(640, 430) Pencerenin başlangıç genişlik ve yükseklik boyutu
Örnek 
local Window = Library:CreateWindow({
    Title = "Toxin Premium",
    Subtitle = "v2.1",
    Accent = Color3.fromRGB(0, 255, 128)
})

-- Canlı renk değiştirme
Window:SetAccent(Color3.fromRGB(0, 180, 255))
Window:CreateTab(name, [iconId])

Sol menüye yeni bir sekme butonu ve sağ alana kaydırılabilir bağımsız sayfa ekler.

→ Returns: Tab Object
Parametre Tip Açıklama
name string Sekme butonunda yazacak başlık
iconId string (opsiyonel) Roblox asset id (örn: "rbxassetid://6031075931")
Tab:CreateSection(title)

Sekme içine kategorileri birbirinden ayıran, ince çerçeveli ve koyu dolgulu şık bir kart ekler.

→ Returns: Section Object
Section:CreateToggle(config)

Pürüzsüz TweenService animasyonuna sahip kayan aç/kapa anahtarı.

→ Returns: Toggle Object { State = bool, Set = function }
Parametre Tip Varsayılan Açıklama
Titlestring"Toggle"Açıklama başlığı
Defaultbooleanfalseİlk açık/kapalı durumu
Callbackfunction(state)nilDurum değiştiğinde tetiklenir
Örnek 
local MyToggle = Section:CreateToggle({
    Title = "Auto Farm",
    Default = false,
    Callback = function(state)
        print("Durum:", state)
    end
})

-- Kod ile değiştirmek için:
MyToggle:Set(true)
Section:CreateSlider(config)

Mobil dokunmatik ve masaüstü fareyle sürüklenebilir, ondalık hassasiyetli kaydırıcı bar.

→ Returns: Slider Object { Value = number, Set = function }
Parametre Tip Varsayılan Açıklama
Titlestring"Slider"Başlık
Minnumber0En küçük değer
Maxnumber100En büyük değer
DefaultnumberMinBaşlangıç değeri
Decimalsnumber0Ondalık basamak sayısı (0, 1, 2)
Callbackfunction(val)nilDeğer değiştikçe çağrılır
Section:CreateDropdown(config)

Tıklandığında aşağı açılan ve seçenek listesini barındıran menü bileşeni.

→ Returns: Dropdown Object { Selected, Set, Refresh }
Parametre Tip Açıklama
TitlestringBaşlık
OptionstableSeçenekler dizisi: {"A", "B", "C"}
DefaultstringVarsayılan seçili öğe
Callbackfunction(selected)Yeni seçim yapıldığında tetiklenir
Section:CreateTextbox(config)

Webhook URL veya kullanıcı adı almak için odaklanma efektli modern metin kutusu.

→ Returns: Textbox Object { Text, Set }
Section:CreateKeybind(config)

Tıklandığında tuş dinleyen ve kullanıcının bastığı tuşu kaydeden bileşen. (Backspace ile sıfırlanabilir).

→ Returns: Keybind Object { Key, Set }
