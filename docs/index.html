Luau · Hızlı Kurulum
local Library = loadstring(game:HttpGet("https://raw.githubusercontent.com/hutamev2/HutameHub-Lib/main/Source.lua"))()

local Hub = Library.new({
    Title     = "MyHub",
    Version   = "v1.0",
    Accent    = Color3.fromRGB(220, 50, 50),
    ToggleKey = Enum.KeyCode.RightControl
})

local Tab   = Hub:CreateTab("Combat")
local Left  = Tab:CreateSection("Silent Aim")
local Right = Tab:CreateSection("Extras", "right")

Left:CreateToggle({ Title="Enable Silent Aim", Default=false, Callback=function(s) print(s) end })
Left:CreateSlider({ Title="FOV", Min=10, Max=500, Default=150, Suffix=" px" })
Right:CreateToggle({ Title="Show FOV Circle", Default=true })
Right:CreateDropdown({ Title="Aim Part", Options={"Head","Torso","HRP"}, Default="Head" })

Library.new(config)

Hub penceresini oluşturur. Tüm tab/section/element bu nesne üzerinden yönetilir.

→ Returns: Hub Object
ParametreTipVarsayılanAçıklama
Titlestring"HutameHub"Topbar'da gösterilen hub adı
Versionstring"v1.0"Hub adının yanında gösterilen sürüm
AccentColor3RGB(220,50,50)Tab underline, slider fill ve aktif checkbox rengi
ToggleKeyEnum.KeyCodeRightControlPencereyi gizle/göster tuşu
Örnek
local Hub = Library.new({ Title="MyHub", Version="v1.3", Accent=Color3.fromRGB(220,50,50) })
Hub:SetAccent(Color3.fromRGB(59,130,246))  -- canlı accent değiştir
Hub:Destroy()                               -- pencereyi kapat

local Hub     = Library.new({ Title="MyHub", Accent=Color3.fromRGB(220,50,50) })

local AimL       = CombatTab:CreateSection("Silent Aim")
local AimR       = CombatTab:CreateSection("Aim Extras", "right")

AimL:CreateToggle({ Title="Team Check", Default=true })
AimL:CreateSlider({ Title="Hit Chance", Min=0, Max=100, Default=100 })
AimL:CreateSlider({ Title="FOV Radius", Min=10, Max=500, Default=150, Suffix=" px" })

AimR:CreateToggle({ Title="Show FOV", Default=false })
AimR:CreateDropdown({ Title="Aim Part", Options={"Head","Torso","HumanoidRootPart"}, Default="Head" })

local SettingsTab = Hub:CreateTab("Settings")
local CfgL        = SettingsTab:CreateSection("Configuration")
local CfgR        = SettingsTab:CreateSection("Webhook", "right")

CfgL:CreateKeybind({ Title="Toggle UI", Default=Enum.KeyCode.RightControl })
CfgL:CreateColorPicker({ Title="Accent Color", Default=Color3.fromRGB(220,50,50), Callback=function(c) Hub:SetAccent(c) end })
CfgR:CreateTextbox({ Title="Webhook URL", Placeholder="https://discord.com/..." })
CfgR:CreateButton({ Title="Destroy UI", Callback=function() Hub:Destroy() end })
Section:CreateMultiDropdown(config)

Aynı anda birden fazla seçim yapılabilen açılır liste. Seçili öğeler checkbox ile işaretlenir, inline özet gösterilir.

→ Returns: { Selected: table, Set(tbl), GetSelected(), Refresh(opts) }
ParametreTipVarsayılanAçıklama
Titlestring"MultiDropdown"Sol taraftaki etiket
Optionstable{}Seçenek listesi: {"Head","Torso","HRP"}
Defaulttable{}Başlangıçta seçili değerler: {"Head"}
MaxShownumber2İnline gösterilen max seçim sayısı (sonrası "+N" olur)
ConfigKeystringnilConfig Save/Load için benzersiz anahtar
Callbackfunction(table)nilSeçim değişince seçili değerlerin table'ını döndürür
Örnek
local mdd = Left:CreateMultiDropdown({
    Title     = "Hitbox Parts",
    Options   = {"Head", "Torso", "HumanoidRootPart", "LeftArm", "RightArm"},
    Default   = {"Head"},
    MaxShow   = 2,
    ConfigKey = "hitbox_parts",
    Callback  = function(selected)
        -- selected = {"Head", "Torso"} gibi sıralı table
        print(table.concat(selected, ", "))
    end
})

mdd:Set({"Head", "Torso"})  -- programatik set
mdd:GetSelected()           -- mevcut seçimleri döndürür
mdd:Refresh({"A","B","C"})  -- seçenekleri güncelle
Hub:Notify(config)

Sağ alt köşeden kayan toast bildirimleri. Otomatik kaybolur, progress bar ve kapatma butonu içerir.

→ Returns: nil (fire-and-forget)
ParametreTipVarsayılanAçıklama
Titlestring"Notification"Kalın başlık metni
Textstring""Açıklama satırı (boş bırakılırsa tek satır)
Typestring"info""info" · "success" · "error" · "warning"
Durationnumber3Saniye cinsinden ekranda kalma süresi
Örnek
Hub:Notify({ Title="Silent Aim", Text="Enabled",        Type="success", Duration=3 })
Hub:Notify({ Title="Error",       Text="API unreachable", Type="error",   Duration=4 })
Hub:Notify({ Title="Warning",     Text="Low FPS detected", Type="warning", Duration=5 })
Hub:Notify({ Title="Update",      Text="v2.1 available",  Type="info" })
Hub:SetWatermark(config)

Ekran köşesinde sabit bir HUD overlay. FPS renk-kodlamalıdır: yeşil ≥50, sarı ≥30, kırmızı <30.

→ Methods: SetWatermark · UpdateWatermark(fmt) · RemoveWatermark()
ParametreTipVarsayılanAçıklama
Formatstring"{player} | {fps} fps"Desteklenen placeholder'lar: {player} {fps} {ping} {time} {game}
Positionstring"TopRight""TopLeft" · "TopRight" · "BottomLeft" · "BottomRight"
BgAlphanumber0.45Arkaplan şeffaflığı (0 = opak, 1 = tamamen şeffaf)
Örnek
Hub:SetWatermark({
    Format   = "{player}  |  {fps} fps  |  {ping}ms",
    Position = "TopRight",
    BgAlpha  = 0.45
})

Hub:UpdateWatermark("{player}  |  {game}  |  {time}")  -- format değiştir
Hub:RemoveWatermark()                                    -- kaldır
Hub:SaveConfig(name) · Hub:LoadConfig(name)

ConfigKey parametresi olan her element otomatik olarak kayıt sistemine dahil olur. Veriler HutameHub_name.cfg dosyasına yazılır (executor'da writefile/readfile gerektirir).

→ Başarı/hata sonucu Notify ile bildirilir
MethodParametreAçıklama
Hub:SaveConfig(name)stringTüm kayıtlı elementleri dosyaya yazar
Hub:LoadConfig(name)stringDosyadan okur ve elementleri geri yükler
Hub:_regElement(key, getter, setter)—Manuel element kaydı (genellikle gerekmez)
Örnek
-- ConfigKey olan her element otomatik kaydedilir:
Left:CreateToggle({ Title="Silent Aim", Default=false, ConfigKey="silent_aim" })
Left:CreateSlider({ Title="FOV", Min=10, Max=500, Default=150, ConfigKey="fov" })
Right:CreateDropdown({ Title="Aim Part", Options={"Head","Torso"}, ConfigKey="aim_part" })
Right:CreateMultiDropdown({ Title="Parts", Options={"Head","Torso"}, ConfigKey="parts" })

-- Kaydet / Yükle:
Hub:SaveConfig("default")  -- → HutameHub_default.cfg
Hub:LoadConfig("default")  -- geri yükler + başarı bildirimi gösterir
