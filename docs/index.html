Initialization

Library.new(config)

Creates a new HutameHub window instance.

Returns:Hub (table)

Config Table Parameters

KeyTypeDescription
TitlestringWindow title (default: "HutameHub")
VersionstringVersion text (default: "v3.0")
Themestring|tablePreset name ("Midnight", "Ocean", "Crimson", "Emerald", "Sakura") or custom table
AccentColor3Custom accent color (overrides theme preset)
ToggleKeyEnum.KeyCodeKey to toggle the UI (default: RightControl)

Controls

Section Elements

Methods available on a Section to create interactive elements.

MethodDescription
CreateToggle(cfg)Creates a checkbox toggle
CreateSlider(cfg)Creates a draggable slider
CreateDropdown(cfg)Creates a single-select dropdown
CreateMultiDropdown(cfg)Creates a multi-select dropdown
CreateTextbox(cfg)Creates a text input field
CreateKeybind(cfg)Creates a keybind listener
CreateColorPicker(cfg)Creates an HSV color picker
CreateButton(cfg)Creates a clickable button
CreateLabel(text, color)Creates a text label
CreateSeparator(text)Creates a dividing line
ℹ
Most controls accept a configuration table with standard keys: Title, Flag, Default, Callback, and ConfigKey.

Core Systems

Global methods available on the Hub instance.

MethodDescription
Hub:SaveConfig(name)Saves all ConfigKey values to a JSON file
Hub:LoadConfig(name)Loads configuration from a JSON file
Hub:ListConfigs()Lists saved configurations
Hub:Notify(cfg)Shows a toast notification
Hub:SetWatermark(cfg)Displays a watermark HUD
Hub:SetTheme(theme)Changes the theme dynamically
